# ANN for Binary Classification on the `make_moons` Dataset

A simple Artificial Neural Network (ANN) built with TensorFlow/Keras to classify the two interleaving half-circles generated by Scikit-learn's `make_moons`. The project walks through the full workflow: data generation, preprocessing, model building, training, evaluation and decision-boundary visualization.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/0xkanagaraj/make-moons-ann/blob/main/moons_ann.ipynb)

## Overview

The `make_moons` dataset is a classic toy problem for binary classification. The two classes are not linearly separable, so a model with non-linear activations is needed. This notebook shows how a small feed-forward network learns a curved decision boundary.

## Workflow

1. **Data generation:** 1,000 samples with `noise=0.2` and `random_state=42`.
2. **Preprocessing:** 80/20 stratified train/test split, followed by feature scaling with `StandardScaler` (fit on the training set only).
3. **Model:** a fully connected network built with `keras.Sequential`.
4. **Training:** Adam optimizer, binary cross-entropy loss, 20% validation split and early stopping on validation loss.
5. **Evaluation:** test loss and accuracy, classification report and confusion matrix.
6. **Visualization:** training curves and the learned decision boundary.

## Model Architecture

| Layer | Units | Activation |
|-------|-------|------------|
| Input | 2 | n/a |
| Dense | 16 | ReLU |
| Dense | 8 | ReLU |
| Dense (output) | 1 | Sigmoid |

| Setting | Value |
|---------|-------|
| Optimizer | Adam (learning rate 0.01) |
| Loss | Binary cross-entropy |
| Batch size | 32 |
| Max epochs | 200 (early stopping, patience 20) |
